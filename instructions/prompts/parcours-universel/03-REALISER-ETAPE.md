# 03 — Réaliser une seule tâche approuvée

Ne code que la tranche explicitement approuvée à l'étape 02 ou une nouvelle tâche précise validée par le propriétaire. **En l'absence d'accord, arrête-toi.**

1. Vérifie rapidement l'état actuel des fichiers, décisions et tests, et les modifications locales. Si la tâche est déjà réalisée, prouve-le et ne la refais pas.
2. Présente brièvement l'effet utilisateur attendu, les fichiers concernés, les risques et les tests. Aucune nouvelle branche, publication, migration ou appel IA facturable sans autorisation.
3. Implémente **une tranche fonctionnelle complète**, pas un squelette ; respecte contenus et design approuvés, préserve les anciens projets et médias.
4. Ajoute et exécute les tests ciblés ; vérifie les erreurs, données vides, accès et régressions pertinentes.
5. Fournis un bilan : fichiers modifiés ; résultat observable ; tests PASS / FAIL / NON EXÉCUTÉ ; limites ; prochaine action. **Ne commite ni ne pousse automatiquement.**

Propose ensuite **04 — Relecture et tests**.
