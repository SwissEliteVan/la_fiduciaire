# PROMPT 29 — AUDIT « AUCUNE FONCTION COMMERCIALE OUBLIÉE »

Parcours l'ensemble du projet et lis son manifest. Produis un inventaire binaire **planifié / présent dans le code / connecté à un service réel / testé**, séparé pour : WhatsApp, téléphone, chat IA, funnel, formulaires, pop-up, blog, cookies/CMP, analytics, SEO, médias, email/CRM, accessibilité, sécurité et performance.

Pour chaque module, donne les fichiers EXACTS qui le réalisent, routes et destinations, données requises, scénario de test, résultat observable et statut. Un bouton visible sans connexion derrière est **UI SEULEMENT**, non intégré. Un numéro non validé est **bloqué**, pas fonctionnel. Un blog avec seulement `/blog` et aucun moyen de publier est **incomplet**. Une bannière qui laisse charger des pixels avant consentement est **échec**.

Constitue la matrice des manques et génère un **prompt de correction précis par module manquant** respectant le stack existant, classé par risque de perte de leads, conformité, sécurité et effort. Aucun refactoring décoratif avant de réparer les fonctions commerciales réelles. Ne considère pas une vérification non exécutée comme réussie.
