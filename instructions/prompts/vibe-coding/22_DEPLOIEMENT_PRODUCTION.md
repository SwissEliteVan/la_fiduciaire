# PROMPT 22 — MISE EN LIGNE SÛRE SELON LE STACK CHOISI

Inspecte configuration réelle. Recommande hébergeur et architecture : hébergement statique pour HTML, hébergement CMS géré ou auto-hébergé selon besoin, backend/serverless si clés/API, plateforme e-commerce si applicable. **Vercel n'est pas imposé.** Comparer prix estimatifs, opérationnalité, coût d'exploitation, sécurité, données et portabilité.

Préparer build, versions verrouillées, staging/preview, secrets, domaine/DNS/TLS, CSP/test scripts tiers, cache CDN, redirections, sitemap, email de notification, sauvegarde et restauration, alertes de formulaires/chat/erreurs, quotas et rollback. Contrôler au lancement l'ensemble du funnel, consentement, WhatsApp et blog.

**Livrer** : `docs/DEPLOYMENT.md` avec commandes adaptées au vrai stack, checklist pré-prod/post-prod, plan de migration si nécessaire, coûts non contractuels, actions requérant autorisation. Ne pas déployer, acheter, modifier DNS ou activer fournisseur payant sans mandat explicite. Tout accès manquant devient une étape bloquante documentée.
