# PROMPT 03 — PLAN DES PAGES, ARCHITECTURE ET MODULES

Lis le manifest et le brief ; inspecte la stack réellement choisie. Conçois l'arborescence du site, les parcours et la séparation technique proportionnée à la complexité. Propose structure minimale si HTML pur ; content/layouts si générateur statique ; modules fonctionnels si application.

**Pages à traiter** : accueil, offres/services, preuve réelle, contact/devis, parcours de conversion, blog index/article, FAQ, mentions et confidentialité, paramètres cookies ; ajouts selon projet. **Modules obligatoirement inventoriés** : WhatsApp, téléphone, chat IA, funnel, formulaire/CRM, pop-up, blog, consentement, SEO, médias, sécurité, accessibilité, performance.

Pour chaque page : URL, intention, objectif, bénéfice, preuves disponibles, sections, champs/actions, médias avec poids/ratio, événements de conversion sans PII, données structurées justifiées, dépendances, parcours d'erreur et accès clavier. Livrer `docs/ARCHITECTURE.md`, `docs/FILE_REGISTRY.md` et `docs/CONVERSION_FUNNEL.md`.

**Contrôle** : aucun fichier fantôme, aucune base de données imposée, aucun blog « prévu » sans système de publication, aucun chat « fonctionnel » sans backend ou fournisseur approuvé.
