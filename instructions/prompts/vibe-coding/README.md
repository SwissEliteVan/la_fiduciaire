# Bibliothèque Vibe Coding — 30 prompts intégrés

Commencer par **01 — Auditer le dossier et proposer une stack**. Il inspecte d’abord le projet réel **sans modifier de fichier**, puis compare les solutions adaptées et présente une recommandation soumise à validation.

Dans le lanceur : **Mode avancé → Prompts de projet (toutes IA) → Vibe coding (30)**. Le cadre commun et le prompt 00 sont ajoutés automatiquement au prompt copié ; ne jamais coller toute la bibliothèque. Aucun appel IA n’est lancé par la copie.

Pour un projet existant, conserver la stack et les décisions actuelles sauf justification et autorisation. Les modules de site commercial ne sont proposés que s’ils sont pertinents. Les étapes coûteuses ou de déploiement restent sous autorisation explicite.

Lire le [manifeste](VIBE_MANIFEST.md) et le [catalogue](catalogue.json) pour les prérequis, les portées et les garde-fous.
