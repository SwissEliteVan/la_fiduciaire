# PROMPT 08 — POP-UP COMMERCIAL ACCESSIBLE ET NON INTRUSIF

Ajoute un module de pop-up marketing configuré pour **[OFFRE VÉRIFIÉE]**. Il doit fonctionner dans le stack choisi y compris HTML/JS pur, sans bibliothèque juste pour ouvrir une modale.

**Paramètres** : pages autorisées, exclusions checkout/formulaire/chat/cookies, déclencheur honnête après engagement/exit intent adapté, fréquence maximale (session ou durée), fermeture X claire, bouton non trompeur, expiration de campagne, version mobile, expérience sans JS si pertinente. L'offre doit être vraie, son lien fonctionnel.

**Accessibilité** : `dialog` natif si pertinent ou gestion correcte du focus, Escape, retour du focus, navigation clavier, pas de contenu essentiel caché ; sans piéger la sortie utilisateur. Aucun affichage agressif au chargement. Animations réduites et limites de poids JS.

**Consentement** : le pop-up de présentation peut ne pas nécessiter de traceur marketing, mais publicité ciblée, profilage ou script tiers doit respecter les règles applicables ; documenter stockage du choix et sa durée.

**Livrer** : fichiers, configuration marketing, règles de priorité pop-up vs consentement vs chat, scénarios de test et mesure de conversion réelle uniquement après instrumentation conforme.
