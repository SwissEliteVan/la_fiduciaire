# PROMPT 09 — BLOG RÉEL ET PUBLICATION SANS SUR-ARCHITECTURE

Conçois et construis un blog adapté au **stack réellement choisi**. Si HTML pur : évalue articles HTML statiques ou mini-générateur ; si CMS : modèles éditoriaux ; si framework : contenu statique, CMS ou API selon besoin. Ne force ni WordPress ni MDX ni base de données.

Inclure index, article type, pagination si volumétrie, catégories/tags raisonnables, auteur/date vérifiables, image de couverture optimisée, fil d'Ariane, liens de services, articles liés, recherche seulement si utile, RSS optionnel, sitemap/canonical, schema Article/BlogPosting valide, prévisualisation, brouillon, workflow création/modification, redirections lors renommage d'URL.

**Anti-hallucination** : ne fabrique aucun auteur, expertise, citation, client, date de publication ou article « déjà publié ». Des sujets proposés doivent être marqués propositions. Les brouillons sont non indexés et non annoncés comme publications.

**Livrables** : arborescence + exemples de gabarits, fichiers complets, documentation publication en moins de 10 étapes, validation de liens/indexation/accessibilité/performance, stratégie de migration si nouveau système.
