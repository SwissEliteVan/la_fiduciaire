# PROMPT 25 — RECHERCHE DOCUMENTATION, SKILLS ET CHOIX D'OUTILS

Pour la tâche **[TÂCHE]**, déduis d'abord les technologies effectivement présentes et les versions. Consulte `references/SOURCES_TECHNIQUES.md` et les sources officielles actuelles utiles, jamais toutes les bibliothèques en vrac. Vercel Agent Skills n'est pertinent pour React que **si React est utilisé** ; les lignes directrices UI peuvent aider n'importe quel stack. `motion.dev/docs/performance` éclaire les animations même sans installer Motion.

**Rechercher** : doc officielle du langage/CMS/SSG/plateforme choisi, image optimization (web.dev et outils compatibles), encodeurs vidéo, Core Web Vitals, WCAG, OWASP Top 10/ASVS, SEO Google, vie privée/consentement selon marché, documentation fournisseurs d'API ou chat choisis.

**Pour chaque référence retenue** : URL officielle, problème traité, version/date vérifiée si disponible, règle applicable, condition de pertinence, limites, action sur le code. Écarter les liens obsolètes, non officiels ou incompatibles avec le stack. Ne jamais installer des skills ou dépendances sans raison documentée ; ne jamais présenter une source lue comme un audit exécuté.

**Livrer** : tableau de sources et décisions techniques, plan concret sans prose vide.
