# Prompt 07 — Interface et parcours utilisateur

Simplifier l'expérience Windows : Créer/Reprendre → Décrire mon produit → Explorer trois identités → Démarrer l'IA → Vérifier → Sauvegarder. Un seul prochain pas clair. Ne pas rajouter des boutons dispersés sans revoir l'organisation.

Créer une fiche à saisie progressive, sauvegarde brouillon, informations optionnelles et reprise ; le choix des styles doit être explicite. UI clavier, lisibilité, haute résolution et mobile si interface web. Aucun lancement IA à l'ouverture du dossier ou lors de la saisie.

Tests : bouton réellement branché, erreur lisible, aucun écrasement, deux projets indépendants, reprise inchangée, distinction commit local vs push GitHub confirmé. Vérifier en contexte Windows réel.
